## 开通前先核对四件事

1. **账号和产品。**确定要升级哪个 ChatGPT 账号，记住当前登录方式。ChatGPT 订阅和 OpenAI API [分别计费](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)，开通 Plus 不会自动得到 API 额度。
2. **地区资格。**查看 [OpenAI 的 ChatGPT 支持地区列表](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)。所在地或付款方式不在支持范围时，不能把跨区账号、虚拟卡或第三方付款理解为消除账号限制的办法；OpenAI [说明了不支持地区的访问与付款风险](https://help.openai.com/en/articles/9131992-chatgpt-and-api-services-in-unsupported-countries-and-territories)。
3. **已有订阅。**先看 ChatGPT 账号里的套餐与账单，再看 Apple App Store 或 Google Play 的订阅列表。同一账号在多个平台分别购买，可能造成[重复订阅和扣费](https://help.openai.com/en/articles/20001043)。
4. **结算方。**官网购买看 ChatGPT 账单；App 内购买先确认实际结算方是 Apple、Google 还是跳转网页；第三方订单要看商家的付款、交付及售后条款。

## 三种方式怎么选

| 路线 | 适用前提 | 操作与账单入口 | 下单前重点 |
| --- | --- | --- | --- |
| 官网网页自行订阅 | 账号、所在地和付款方式符合当前官方要求 | 在 [chatgpt.com](https://chatgpt.com/) 登录并升级；网页购买由 ChatGPT Billing 管理 | 套餐、币种、支付方式及已有订阅 |
| 官方手机应用 | 官方 App 中出现可用的升级与结算选项 | 在 App 内确认流程；Apple、Google 或网页结算由各自平台管理 | 原 ChatGPT 账号、商店账号、结算方及重复扣费 |
| 第三方代充 | 已看清交付方式、账号授权和售后规则 | 商家网站下单；在商家订单页和本人 ChatGPT 账号分别核验 | 权益进哪个账号、需提交什么、费用与失败处理 |

有符合条件的官方自助付款方式，可以先走前两条路线。没有方便可用的方式，或希望有人协助操作，再按[第三方筛选清单](https://laoma528.github.io/GPTplusSub/third-party.html)比较交付和售后。**支持地区的要求仍要先核对**。

## 方案一：在 ChatGPT 官网自行订阅

1. 打开 [ChatGPT 官网](https://chatgpt.com/)并登录**准备开通订阅的那个账号**。先在设置中确认当前套餐，避免在另一个账号或平台已有有效订阅。
2. 从个人资料或套餐入口选择“升级套餐 / Upgrade plan”，查看账号实际提供的套餐、金额、币种和付款选项。按钮文字可能随界面变化；[OpenAI 的 Plus 说明](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)列出了网页登录和升级的基本流程。
3. 依照结算页填写受支持的付款信息；提交前再核对账号、套餐、周期和应付金额。[OpenAI 支付方式说明](https://help.openai.com/en/articles/10421635-multicurrency-billing)按地区列出可用选项，不能把某一地区的方式套用到所有账号。
4. 支付完成后，回到**同一个 ChatGPT 账号**，在设置的套餐与 [Billing 页面](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)核对权益及账单记录。

**付款被拒怎么办？**先看具体报错，核对卡片资料、账单地址、余额、银行验证以及所在地和发卡地区。若银行拒绝，联系发卡行；不要反复使用来源不明的卡或编造账单资料。可按 [OpenAI 的信用卡拒付排查](https://help.openai.com/en/articles/7232916-why-was-my-credit-card-declined)和[续费失败说明](https://help.openai.com/en/articles/7242622-troubleshooting-chatgpt-plus-or-pro-renewal-payments)继续检查。更细的准备清单见[在线自助订阅指南](https://laoma528.github.io/GPTplusSub/self-subscribe.html)。

## 方案二：通过官方手机应用订阅

1. 从设备的正式应用商店打开官方 ChatGPT 应用，使用**原来准备开通的 ChatGPT 账号**登录。先检查该账号以及 Apple / Google 商店里是否已有续费中的订阅。
2. 在 App 中打开可用的“升级 / Upgrade plan”入口，查看实际套餐与结算页面。以屏幕显示的结算方为准：有些流程在应用商店完成，也可能跳转网页；[OpenAI 的 iOS 升级说明](https://help.openai.com/en/articles/7905739-chatgpt-ios-app-upgrading-to-a-paid-subscription)提醒要确认这一点。若 App 没有提供所需套餐，可查看官网是否有适合该账号的选项。
3. 结算前确认当前 ChatGPT 账号、商店账号、价格、周期和支付方式。由 Apple App Store 或 Google Play 购买的订阅，会同时关联购买时登录的 ChatGPT 账号和相应商店账号；不能假设换一个 ChatGPT 账号就能沿用原购买。[账号关联排查](https://help.openai.com/en/articles/20001056-troubleshooting-subscriptions-linked-to-another-chatgpt-account)列出了这种情况。
4. 支付后仍用**购买时的 ChatGPT 账号**核对套餐。以后要取消或查找扣费，先根据收据确认结算方，再到对应平台管理；[OpenAI 的取消说明](https://help.openai.com/en/articles/7232927-canceling-your-chatgpt-subscription)列出了网页、Apple 和 Google 的路径。

如果扣款成功但账号仍显示免费，不要立刻在另一个平台再买一次。先核对原 ChatGPT 账号与收据；Apple 内购可在对应账号的 App 设置中尝试[恢复购买](https://help.openai.com/en/articles/20001056-troubleshooting-subscriptions-linked-to-another-chatgpt-account)，仍有问题再联系相应支持渠道。

**想用 Apple 礼品卡余额付款？**这是 Apple 账户里的余额，只有在 Apple 实际承接结算、地区和账号条件允许时才可能用于应用内购买；[Apple 说明](https://support.apple.com/en-la/118245)指出，部分订阅即使用余额也可能要求绑定付款方式，礼品卡还受[购买地区与兑换地区](https://support.apple.com/en-gb/108285)限制。它与 [OpenAI Gift Card](https://help.openai.com/en/articles/20001491-buying-and-redeeming-openai-gift-cards)是两种不同产品，后者的适用地区和网页兑换条件另算。付款前以 Apple 和 ChatGPT 实际结算页面为准，不照搬他人的账号地区、账单地址或成交价。

## 付款后怎么核验、出问题怎么办

无论走哪条路线，保留**不含敏感凭据的付款记录**，按下面三项核对：

1. **付款记录在哪？**官网结算看 ChatGPT Billing，应用内购看 Apple / Google 的收据，第三方服务看商家订单页。付款成功与 ChatGPT 权益开通是两个要分别确认的状态。
2. **权益在哪个账号？**用付款时的 ChatGPT 账号及同一登录方式进入，检查当前套餐。App 内购遇到“关联另一个账号”提示，先按[OpenAI 账号关联说明](https://help.openai.com/en/articles/20001056-troubleshooting-subscriptions-linked-to-another-chatgpt-account)排查，不要立即重复购买。
3. **问题交给谁？**网页订阅和官方账号问题按 [OpenAI 帮助中心](https://help.openai.com/)处理；Apple / Google 购买先按相应平台与 OpenAI 的指引核对；ProdClub 订单按其[帮助与售后页面](https://prodclub.xyz/help)处理。退款责任、条件与处理时间以实际结算方的当前规则为准。

**常见问题：**

- **没有国际信用卡，就一定要代充吗？**先核对所在地资格、官网可用方式和官方 App 实际显示的结算选项。符合条件的读者可以自行订阅；若选择第三方，则按上面的账号交付与售后清单判断。
- **买了 Plus，API 能直接用吗？**不能。ChatGPT 个人订阅与 API 账单分开管理。
- **付款成功但没有显示 Plus？**先核对账号、登录方式和结算方，查看商家订单或官方收据；不要先换平台再付一次。
- **想取消或退款？**先找出实际结算方。官网、应用商店、第三方商家各有自己的管理入口与规则。
