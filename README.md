## 三个常见错误，先避开

- **已有 Plus 还买这款 Plus。**当前商品不能覆盖已有 Plus，等原订阅结束、账号回到 Free 再下单。
- **把 Session 发到聊天工具。**它相当于登录凭据，只应粘贴进对应订单的提交框。复制不完整时，回到 Session 页面重新全选，不要经微信转发。
