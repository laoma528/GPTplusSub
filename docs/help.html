付款没有完成

回到原订单确认支付状态。只有确认未支付时，再按订单提示继续付款。

付款成功，仍未开通

检查订单是否要求继续提交 Session 或其他必要信息，再查看交付状态。

确认当前登录的是充值时使用的账号，刷新订阅状态后再核对。

通过原订单页面联系售后，说明订单号与问题。退款条件和处理以当次商品及订单规则为准。
