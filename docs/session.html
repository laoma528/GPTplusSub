关键步骤

Session 怎么拿？从登录到粘贴订单页，逐步做。

ProdClub 的自有账号开通流程会在付款后要求提交一次 Session。它相当于登录凭据；下列步骤只适用于你自己正在操作的订单。

复制 Session 的 5 个动作

  1. 保留 ProdClub 订单页

    付款确认后，订单页会提示提交 Session。先别关闭；若关了，到下单邮箱里找订单链接。

  2. 在同一浏览器登录 ChatGPT

    另开标签页访问 chatgpt.com，登录你要开通 Plus 的账号。浏览器里如果有多个账号，先看头像和设置里的邮箱，确保没有登录错。

  3. 打开 Session 地址

    在这个浏览器的新标签页输入 https://chatgpt.com/api/auth/session。正常情况下会看到一整段文本。不要把这段文本粘贴给任何聊天机器人，也不要截图。

  4. 完整复制

    Windows 按 Ctrl + A、Ctrl + C；Mac 按 ⌘ + A、⌘ + C。手机长按内容，选“全选”和“复制”。不要手动截取其中一段。

  5. 只回到对应订单页提交

    把完整内容粘贴到 ProdClub 订单的 Session 输入框，按页面按钮提交。随后在订单页等结果；商家说明开通后会删除用于开通的 Session。

你交出的是什么？Session 不是密码，但拿到它的人可能暂时取得相应登录权限。只在你信任且主动下单的订单流程里提交。不要把它发给客服私聊、群聊、GitHub Issue，也不要随订单号一起截图传播。

出现提示时，按文字对照处理

页面提示你现在做什么
“没有 accessToken”通常是打开 Session 地址时还没在同一个浏览器登录 ChatGPT。先完成登录，再重新打开 Session 地址，全选复制。
“Session 不完整”回到 Session 页面重新全选复制，确认末尾也复制到。不要经过微信等聊天软件转发内容；直接从浏览器粘贴到订单页。
复制后还是旧内容重新登录 ChatGPT，再打开 Session 地址取新的内容。不要反复提交同一段已过期的文本。
人机验证卡住这是 ChatGPT 页面自身的验证。可先关闭会干扰页面的广告拦截插件并刷新；如果仍不能完成，暂停订单操作，按 ChatGPT 页面提示处理，不要找人代做验证。
订单让你再提交说明上一次没有完成开通。重新取得 Session 后在同一订单重交；若转人工，保留订单号等商家处理。

如果你已经把 Session 误发到公开位置，先删除公开内容、退出相关登录会话并重新登录，再联系相应平台支持；不要继续使用已经外泄的凭据。
