海外卡 · 官网直付

手里有海外银行卡，怎么在官网直接订阅 Plus？

适用条件：本人和发卡银行都位于 OpenAI 支持地区。

国内银行卡不支持官网直付，包括国内银行发行的双币 Visa、Mastercard 卡。

付款前准备三样东西

  • 准备要升级的 ChatGPT 账号；已有 Plus 时先确定原订阅在哪个平台。
  • 准备真实可用的海外信用卡或借记卡，向发卡银行确认支持线上、国际和定期扣费，且可完成 3D Secure / 银行 App 验证。
  • 准备这张卡在银行登记的真实账单姓名、地址和邮编；付款页不要填与银行记录不符的地址。

从官网到支付成功，逐步点

  1. 登录并核对套餐

    在浏览器打开 chatgpt.com，用要开通的账号登录。点头像或菜单 → Settings / 设置，确认当前套餐及账单状态，避免再次买到已有的 Plus。

  2. 选择 Plus

    点“Upgrade plan / 升级套餐”，在个人套餐里选“Get Plus”。不要选团队版、Pro 或 API 余额。

  3. 核对价格与续费日期

    在结算页先读清月费、币种、税费与续费日期。网页结算按页面实际金额收费；当地税可能使总额高于基础套餐价。

  4. 填写银行卡资料

    在卡资料框填卡号、到期月年和 CVC；账单姓名、地址、城市、州省和邮编按发卡银行记录填写。逐项确认后提交一次，不要连续点付款按钮。

  5. 完成银行验证

    银行若弹出 3D Secure 验证，按银行 App 或短信完成确认，保持结算页打开。关闭弹窗或验证码过期会导致付款失败。

  6. 检查订阅与收据

    完成后回原 ChatGPT 账号，打开 Settings → Billing / 账单核对 Plus、收据及下次扣款日期。保存收据；下月不用时从同一账单页取消，别只锁卡。

卡被拒后怎么定位

情况处理
中国大陆发行的国际卡被拒OpenAI 要求发卡银行位于支持地区；只换账单地址不能改变发卡地。不要反复试同一张卡。
支持地区发行的卡被拒核对卡号、有效期、CVC、银行记录中的账单地址、余额与银行交易限制；联系发卡行说明是境外在线周期订阅。
3D Secure 未完成允许支付验证弹窗和跳转，在银行 App 完成批准；仍不弹出时用无痕窗口或换浏览器，并让银行核查验证是否启用。
有扣款却没 Plus先看收据与同一账号的 Billing，确认是否只是银行预授权；联系 OpenAI 支持并附交易时间、错误文字，不发送完整卡号。

没有受支持地区银行卡的人，可比较 Apple 礼品卡路线、虚拟卡条件与费用和 第三方代充服务，但这些路线都不会改变 OpenAI 官方地区限制。
