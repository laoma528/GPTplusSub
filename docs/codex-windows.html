下载后，自己核对这几项

  1. 看下载来源

    在浏览器下载记录中查看实际下载地址，通常来自微软的 microsoft.com 域名。

  2. 看发布者

    双击安装包，检查安装窗口是否显示“发布者：OpenAI”。

  3. 由 Windows 检查签名

    Windows 安装时会验证包签名；文件被篡改会导致签名校验失败。不要跳过签名错误继续安装。

这条下载路线提供的是原版 .msix 包，不需要额外运行第三方 .exe 安装器，也不需要把 Codex 配置为第三方接口。

三步装好

  1. 安装文件

    双击下载好的 .msix，核对发布者后点击“安装”。如出现允许更改的提示，确认是这次安装再继续。

  2. 从开始菜单打开

    安装后，在开始菜单找到“ChatGPT”，Codex 在应用内。

  3. 登录账号

    使用自己的 ChatGPT 账号登录。应用后续会自动更新。

遇到这些情况怎么办？

浏览器提示“不安全的下载”或“通常不会下载此文件”

原页面说明，部分微软下载地址使用 HTTP，可能触发浏览器提醒。先核对实际来源，再决定是否选择“保留”；安装时继续检查发布者和 Windows 签名结果。

双击没反应，或提示需要“应用安装程序”

系统可能缺少应用安装程序组件，精简版 Windows 较常见。可以使用 PowerShell 安装：右键开始按钮，打开“终端（管理员）”；Windows 10 上可打开“Windows PowerShell（管理员）”。

输入下面的命令和一个空格，再将下载好的文件拖进窗口，确认完整文件路径后按回车：

Add-AppxPackage -Path
