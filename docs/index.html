付款前，按这个顺序查

四个问题能帮你分清订阅资格、账单归属和售后责任。

所在地区是否受支持？

先看 OpenAI 的支持地区列表。服务或支付方式不在支持范围内时，可能出现账号限制。

准备购买哪种产品？

ChatGPT 个人订阅与 API 分开计费。买 Plus 不等于获得 API 额度。

谁负责扣费和续费？

官网、Apple、Google 的账单入口不同。先检查已有订阅，避免重复付款。

出现问题找谁？

官网账单找 OpenAI 支持；应用内购找对应商店；第三方订单按该商家的公开售后规则处理。
