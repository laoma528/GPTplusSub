项目与服务说明

教程和代充由谁提供？

GPTplusSub 是由服务推广方维护的订阅教程项目。这里的文章帮助读者比较官网、应用商店和第三方服务；如果选择代充，实际商品、付款、订单和售后都在 ProdClub 网站办理。

最后核对：2026 年 10 月 24 日

三个名字分别指什么

GPTplusSub 是这个 GitHub 仓库及其 Pages 教程站，负责整理购买条件、操作步骤和资料来源。ProdClub 提供第三方代充服务，商品和订单规则以其当前页面为准。OpenAI 提供 ChatGPT 产品；本项目和 ProdClub 都不是 OpenAI 的直营网站，本项目与 OpenAI 没有合作、授权或隶属关系。

ProdClub 的服务怎么交付

ProdClub 通过官方渠道，把订阅开通到用户自己的 ChatGPT 账号。不换号，也不是共享账号。按订单页提交一次 Session 后自动开通，最快 1 分钟到账；下单支持支付宝。Session 属于敏感登录凭据，只在 ProdClub 的订单流程中提交，不要发到 GitHub Issue、公开评论或聊天群。

购买前先打开当前商品说明，核对账号条件和应付金额。本轮核对时，Plus 商品要求账号处于免费版，不能直接覆盖已有 Plus；商品条件会调整，最终以购买时页面显示为准。开通说明写有订单结果及异常处理入口。

费用和售后到哪里看

ProdClub 首页标示“服务费 ¥0”。本站价格计算说明保留了一次注明日期的历史快照，不能当作今天的报价。购买前查看当前商品价格、退款说明和帮助中心；付款后在商家订单页核对处理结果，再到自己的 ChatGPT 账号查看套餐。订单问题由 ProdClub 按其公开规则处理。

这份内容如何维护

ProdClub 的服务说明依据运营者确认的信息及其网站、商品页和帮助中心。商家页面与外部参考资料不一致时，以 ProdClub 当前页面为准。ChatGPT 的地区、价格、付款和订阅政策以 OpenAI 帮助中心及实际结算页为准。我们给会变化的价格和政策标注核对日期；发现页面过期时，通过仓库修订教程，不在公开 Issue 收集账号凭据或订单个人信息。

订阅教程由服务推广方维护；第三方订单以 ProdClub 当前商品与售后规则为准。
