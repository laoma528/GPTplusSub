官方自助订阅

自己在 ChatGPT 官网付款，实际要点哪些按钮？

这条路线只适合人和付款方式都符合 OpenAI 当前支持条件的读者。中国大陆不在官方支持地区名单里；在大陆的读者不要把换卡、改账单地址或找别人付款理解为获得官方支持。

面向中国大陆地区用户

大陆读者先看结论

OpenAI 的 ChatGPT 支持地区列表没有中国大陆；其官网支付说明没有中国大陆支付宝或微信直付。下面的官网步骤是给实际位于受支持地区，且发卡机构也在受支持地区的人使用的。

官网网页：从登录到核对账单

  1. 确认登录账号

    在浏览器打开 chatgpt.com，登录要升级的账号。先点头像，进入“设置 / Settings”→“账单 / Billing”，确认没有正在生效的 Plus，也没有网页端已经在扣费的订阅。

  2. 选择升级套餐

    回到 ChatGPT，点头像或页面里的“升级套餐 / Upgrade Plan”；根据 OpenAI 当前说明，选择“Get Plus”。不要误选 Pro 或 API 额度。

  3. 填写账单与付款资料

    在结算页核对套餐、月付金额、税费、币种、下一次扣费日期，再填入属于受支持地区发卡机构的信用卡或借记卡。OpenAI 当前公布的网页通用方式是信用卡和借记卡，部分地区另有本地方式；中国大陆支付宝、微信并未列在网页方式里。

  4. 验证并核对订阅

    完成银行要求的 3D Secure 等验证，不要在验证过程中关闭结算页。付款后回到同一 ChatGPT 账号，在“设置 → 账单”查订阅和收据；头像/套餐处应显示 Plus。

如果银行卡被拒，按 拒付症状教程区分地区、发卡行、余额、账单资料和验证，不要盲目反复尝试。

官方 iPhone / Android App：谁扣钱就到谁那里管

  1. 安装官方 App

    从设备的正式应用商店安装官方 ChatGPT App，登录准备开通的那个 ChatGPT 账号。先检查手机系统“订阅”列表及 ChatGPT 网页账单，确认没有别处仍在扣同一订阅。

  2. 确认购买渠道

    在 App 里点“升级 / Upgrade”，核对实际弹出的结算方。如果弹出 Apple App Store 或 Google Play 付款界面，订阅由该商店管理；如果跳到网页，就按网页账单路径处理。

  3. 核对账号与含税金额

    付款前再次确认当前 ChatGPT 账号、Apple/Google 商店账号、套餐和应付金额。买完回到 App 查看 Plus；若显示 Free，先在 App 的设置里尝试“恢复购买 / Restore purchases”，并检查自己是否登录了付款时的 ChatGPT 账号。

付款后找不到 Plus 时

先查看收据上的结算方：OpenAI 网页、Apple 还是 Google。再核对 ChatGPT 登录邮箱和登录方式。若通过 Apple 登录时选过“隐藏我的邮箱”，可能看到 Apple 私密转发邮箱；按原来的“通过 Apple 继续”登录。

确认不是登录错账号后，退出重登；App 内购可在设置里恢复购买。不要马上换平台再买一次，否则可能出现两份订阅。

以后从哪里取消

网页购买：ChatGPT 头像 → Settings → Billing → Cancel plan。Apple：iPhone“设置”→你的姓名→“订阅”→ChatGPT→取消。Google：Play 商店→头像→“付款和订阅”→“订阅”→ChatGPT→取消。
